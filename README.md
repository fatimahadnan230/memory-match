# ✨ Memory Match ✨

A delightful, cozy, and fully responsive memory card matching game built with vanilla JavaScript, Tailwind CSS, and Web Audio API. Designed with a soft pastel aesthetic for the Game Development Society!

## 🎮 Features
* **Multiple Difficulty Levels:** Choose between Easy (4 pairs), Medium (6 pairs), and Hard (8 pairs).
* **Cute Pastel Theme:** Soft glassmorphism UI, rounded cards, and adorable icons (Boba, Bunny, Kitty, Star, and more).
* **Immersive Audio:** Built-in Web Audio API sound effects for card flips, matches, and victory celebrations without external audio files.
* **Responsive Design:** Looks and plays wonderfully on both desktop browsers and mobile phones.

## 🚀 Built With
* **HTML5**
* **Tailwind CSS** (via CDN)
* **JavaScript (ES6+)**

## 🕹️ How to Play
1. Click or tap any card to flip it over and reveal the icon.
2. Find its matching pair by flipping a second card.
3. If they match, they stay open! If not, they flip back over.
4. Match all the pairs in the fewest moves and fastest time possible to win!
